# Инструкция по тестированию модуля отделов

## 🚀 Как протестировать

### 1. Запуск приложения
Приложение уже запущено и работает! 

### 2. Переход к тесту отделов
1. В главном экране найдите синюю кнопку **"Тест модуля отделов"**
2. Нажмите на неё для перехода к тестовому экрану

### 3. Тестирование функций

#### ✅ Базовые тесты:
1. **Обновить** - загружает список отделов из SQLite
2. **Добавить тест** - создает новый тестовый отдел
3. **Синхронизация** - синхронизирует с Supabase (если настроено)

#### ✅ Что проверить:
- [ ] Отделы загружаются из SQLite
- [ ] Можно добавлять новые отделы
- [ ] Статус синхронизации отображается корректно
- [ ] Синхронизация работает (если Supabase настроен)

### 4. Проверка логов
В консоли должны появиться сообщения:
```
Инициализация приложения...
Инициализация SQLite для десктопа...
SQLite инициализирован
Инициализация Supabase... (если настроено)
Supabase инициализирован успешно
Запуск приложения...
```

### 5. Тестирование через UI
1. Перейдите в боковое меню → **"Отделы"**
2. Проверьте полнофункциональный интерфейс:
   - Список отделов
   - Поиск
   - Добавление/редактирование
   - Удаление
   - Синхронизация

## 🔧 Настройка Supabase (опционально)

Если хотите протестировать синхронизацию:

1. Выполните SQL-скрипт `scripts/create_departments_table.sql` в Supabase
2. Убедитесь, что в `lib/core/supabase_config.dart` указаны правильные ключи
3. Перезапустите приложение

## 📊 Ожидаемые результаты

### Без Supabase:
- ✅ Локальная работа с SQLite
- ✅ CRUD операции
- ✅ Статус "pending" для новых записей

### С Supabase:
- ✅ Двусторонняя синхронизация
- ✅ Статус "synced" после синхронизации
- ✅ Данные сохраняются в облаке

## 🐛 Отладка

Если что-то не работает:
1. Проверьте логи в консоли
2. Убедитесь, что нет ошибок компиляции
3. Проверьте, что SQLite инициализирован
4. Проверьте подключение к Supabase (если используется)
